# 历史适配摘要

这里记录历史补丁的证据与验证边界。当前安装资格以管理器检查和 [版本配置](../../engines/localization/profiles/) 为准。静态扫描、隔离组件、真实欢迎页和登录后流程的覆盖范围各不相同。

## 2.23.0：初始适配与补丁 0.4.0–0.4.1

- 确认应用由 Electron 和本地语言服务组成，使用 ASAR 内的 preload 与原生模块提供汉化；不修改 EXE 或语言服务。隔离副本通过安装、重复安装、恢复及中英文往返。早期实机服务超时，未完成登录后流程。证据见 [初始分析](../evidence-summary.json)、[词库来源](../translation-coverage.json)和 [0.3.0 组件回归](../audits/ui-coverage-0.3.0.json)。
- 0.4.0 全包 AST 提取了 2,733 个候选、322 处动态模板；代表性组件验证了动态更新、英文还原和用户内容保护。人工检查遗漏主题模块，0.4.1 补齐并在隔离组件中验证了回调值、主题品牌、颜色、代码与英文偏好持久化。
- 前端主脚本 SHA-256：`867d1990b61d87f4b9ff8c5ecb1551c8688135267f32e56e02563f2d3e78fd68`。原版和历史补丁指纹见 [2.23.0 配置](../../engines/localization/profiles/2.23.0.json)。

## 2.23.1：补丁 0.5.0 适配

- 新旧 ASAR 各有 738 个打包成员，仅 `package.json` 变化；语言服务内嵌的 JS 和 CSS 有更新。前端 AST 候选无新增文案，差异集中在授权选择、项目引导和滚动布局。真实欢迎页另发现 8 条历史漏译，补齐后验证了中英文切换和英文偏好重启。
- 隔离副本通过版本、指纹、安装恢复及内容保护验证。已知补丁仍可凭匹配备份恢复，即使语言服务变更。登录后动态内容和系统原生菜单未逐项实测。
- 前端主脚本 SHA-256：`ad12ecf66061edab6a3835d1360e1bad50787bc7b2f2c9d86568281360864696`；语言服务及 ASAR 指纹见 [2.23.1 配置](../../engines/localization/profiles/2.23.1.json)。本地提取与隔离运行记录原存于 `artifacts/adaptation/2.23.1/`，未随仓库提交。

## 补丁 0.5.1：下拉菜单

- 在仍安装 0.5.0 的真实 2.23.1 上只读复现安全预设和主题下拉漏译。0.5.1 在隔离副本验证了延迟挂载、权限说明、主题品牌、原始选项值及回调、中英文还原和用户内容保护。该实机观察不等同于 0.5.1 实机验收。
- 两个已支持版本的补丁均通过确定性重建。历史补丁指纹见对应版本配置，本地观察与隔离记录原存于 `artifacts/dropdown-0.5.1/`。

## 2.35.2 · 补丁 0.3.0

- Windows 原版 ASAR 与语言服务均已更新。补丁沿用主界面 WebContentsView 的广播和发送者校验。45 项原生替换规则匹配，补齐个性化引导、SSH 连接、浏览器数据与代理设置等 44 条固定文案。主前端脚本 SHA-256 为 `494f0599aa61a7fa97eea7d5d7ab6cd14ddf05866a0bfb0c709a2d75ddfcb58c`。安装与恢复使用 [2.35.2 兼容配置](../../engines/localization/profiles/2.35.2.json) 中的已验证指纹。
- 使用桌面启动器和独立路径运行测试副本，默认和 WebContentsView 参数下均验证真实启动引导、切回英文及重启持久化。问候翻译保留显示名，输出遮盖该问候。组件回归覆盖问候节点复用、浏览器建议及自动化摘要保护、英文还原。验证记录在本地 `artifacts/adaptation/2.35.2/runtime-final/` 和 `runtime-wcv/`。启动器模式不读取原生菜单，账户内会话、市场与远程连接流程未逐项验证。
- 最终 Go 管理器在隔离副本验证了不匹配的语言服务拒绝安装、重复安装和原版恢复。Go 与 Node 补丁对四个已支持版本逐字节一致。
