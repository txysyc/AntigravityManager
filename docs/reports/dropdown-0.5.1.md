# 0.5.1 下拉菜单漏译修复

本次为既有支持范围内的修订：补丁 0.5.1，管理器仍为 0.1.2，支持已验证的 2.23.0、2.23.1。没有增加新的应用版本或放宽指纹检查。此前适配结果见 [0.5.0 报告](adaptation-2.23.1.md)。

## 原因与处理

真实 2.23.1 的安全预设下拉菜单复现了 `Full machine`、`Turbo mode` 及三条说明漏译。它们来自配置的 `displayName`、`shortDisplayName`、`shortDescription`、`longDescription`，旧 AST 扫描没有包含这些字段；运行时已有的 `role="option"` 识别能够覆盖实际弹出层，无需扩大 DOM 替换范围。

新增 99 条固定词条，词库共 2,644 条。包括安全预设标题、短说明和长说明，以及源码确认的对话、标签页、模型管理、通知、GitHub 权限等菜单文案。中文保留原文的权限含义，尤其区分“终端命令仍需审核”与“关闭所有安全防护”。

`Catppuccin`、`Gruvbox Material` 等主题品牌保留原文；`One Light`、`One Dark Pro`、`Solarized Light/Dark` 以原名附明暗中文标注。实际主题键、预设 ID、选项值、存储内容及回调参数保持不变。

审查工具增加上述四种字段及显式 `--source`、`--output`。对完整新版主包提取 2,795 个候选与 327 个动态模板。候选包含模型品牌、内部元数据、调试界面及第三方内容，不能把未命中数视为漏译数，也不能据此宣称全应用覆盖。

## 实机与隔离验证

通过用户桌面已有 `AntigravityLauncher.exe` 启动真实应用，沿用系统代理，仅用回环调试端口只读检查。观察安全预设、计划审核、浏览器 JavaScript 执行策略及浅色主题预设弹出层；记录位于 `artifacts/dropdown-0.5.1/real-menus.json`。没有选择策略或主题，没有修改真实偏好、用户目录或应用文件。实机运行的是用户已安装的 0.5.0，因此这些观察用于确认漏译与 DOM 结构，不充当 0.5.1 实机验收。

隔离 Electron 使用 2.23.1 完整便携副本、独立数据目录和 0.5.1 ASAR，按观察到的 portal/option 结构验证：延迟挂载与重新挂载、权限说明、主题品牌、选项原始值及点击回调、中英文精确还原、同名项目/聊天/代码保护、英文偏好新进程恢复。样本位于 `engines/localization/tests/fixtures/full-audit.html`，运行记录与截图位于 `artifacts/dropdown-0.5.1/smoke/`。首次受限运行的渲染目标崩溃，允许独立测试进程运行后重跑通过；未将首次失败记为成功。

Node 引擎测试 25 项通过；C# 检查含已验证原版元数据链路 23 项通过；规范检查 69 项及空白检查通过。自包含发布包在独立管理器数据目录通过三个页面、四个模块页签与明暗主题检查，正确区分“可用 0.5.1”和“已安装 0.5.0”，截图与结果见 `artifacts/dropdown-0.5.1/manager-published/screenshots/`。

两版 0.5.1 已分别构建，并通过同一目录的确定性重建检查；旧 0.4.1、0.5.0 产物、兼容指纹及原始备份保留。真实应用 ASAR 复核仍为 `4183eae080856c23bef4e915335d59a03323425f71291440d7448b61c3f41d7d`。完整登录后流程、第三方动态菜单与所有系统集成仍未逐项实测；用户应完全退出 Antigravity 后，再用管理器安装修复。
