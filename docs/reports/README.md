## 如何阅读

- 静态候选与字面量命中数用于定位检查对象，不等于可见页面的翻译覆盖率。
- 组件样本、真实产品页面、管理器 GUI 与原生系统菜单的验证范围分别记录。
- 历史路径、指纹与检查数字保留当时含义；目录变更可参照 [工作区迁移](../workspace-migration.md)。
- 提取资源与运行产物不纳入 Git，说明见 [分析资料索引](../../analysis/README.md)。

当前发行的变更摘要见 [更新记录](../../CHANGELOG.md)。
