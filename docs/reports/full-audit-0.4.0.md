## 检查方法

对整个 9.9 MB 前端使用 Babel AST 提取 React 文本子节点和 label/title/description/tooltip/placeholder 等字段，避免正则跨嵌套模板错位。共提取 2733 个去重候选和 322 个动态模板；候选包含内部配置、品牌、技术标识及非展示元数据，不能用作页面覆盖率。脚本 `scripts/audit-ui.cjs`，完整库存 `output/ui-audit.json`。

按功能核对候选及源码偏移，再复扫尚未收录的 React 文本。初版 476 条扩展为 2521 条界面词条；另保留 14 条截图确认的服务端文案和 34 条动态规则。来源分别见 settings、features、conversation 的 candidates/provenance/dynamic 文件及 extra 补扫文件。没有将未知服务端描述或截断内容猜写为完整译文。

## 实现与用户内容保护

仍通过 app.asar preload 实现；不修改 EXE 或 language_server.exe。保持精确映射、原文记录和中英文即时切换。动态规则完整匹配句式，保留版本、数量和名称；时间解析失败时保留原文。

新增保护包括：排队卡用户消息、自动化名称、市场插件名称、模型名称/菜单项、浏览器页面标题、文件名、内联资源、权限应用标题、规则/技能名和日志。项目名与固定标签相同时按实际分组结构区别。代码、终端、输入值、聊天正文、品牌名与百分比不作为一般界面文案翻译。短语法片段与计数后缀有独立范围约束。

市场高亮描述按原文合并匹配，再修改原有文本节点；不移除高亮元素或事件，英文可恢复原文。中文高亮分配依据字符长度，不能声称与搜索词语义精确对齐。

固定工具标题动画采用局部 CSS 显示完整中文，同时保留原 React 子节点；仅匹配已确认前缀，动态内容和路径不参与。英文移除该显示标记，恢复原动画。
