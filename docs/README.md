## 分析与验证报告

[历史报告索引](reports/README.md) 按版本整理逆向、适配和翻译审查结果。[分析资料说明](../analysis/README.md) 解释候选清单与本地提取资源。

报告记录对应版本和验证范围，不能用于自动批准新版本兼容性。组件样本与静态候选数量不代表全部页面已覆盖。
