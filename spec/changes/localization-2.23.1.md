# Antigravity 2.23.1 适配

状态：已完成。正式兼容配置已在隔离验证完成后登记；该适配验证未写入真实安装。后续漏译修复与真实安装观察见 [0.5.1 摘要](../../analysis/reports/README.md#补丁-051下拉菜单)。

## 目标与范围

- 为 Windows Antigravity 2.23.1 的指定 ASAR 和语言服务指纹适配汉化。
- 补丁升级为 0.5.0；管理器升级为 0.1.2，保持各自版本独立。
- 保留 2.23.0 配置、历史补丁识别、原始备份和 `v0.4.1` 源码标签。

## 行为与约束

- 2.23.1 同时绑定 ASAR 与 `resources/bin/language_server.exe`，防止只匹配 Electron 包却使用未经验证的前端。
- 默认构建产物和管理器缓存按应用版本、补丁版本分开；同一产物目录仅允许完全一致的重建，不覆盖不同或不完整产物。
- 补丁内部记录构建版本，已安装版本按匹配的产物或安装记录识别；其他安装的记录不得影响当前版本展示。
- 语言服务不匹配时拒绝新安装；已知汉化文件仍可用匹配的原始 ASAR 备份恢复。
- 新版本未验证前使用候选配置和完整便携副本；真实安装与用户数据保持只读。

## 实现与验收

1. 比较全部 ASAR 成员、内嵌前端资源与相关 UI 源码，保留 REA 证据和覆盖限制。
2. 验证新增版本的安装、重复安装、损坏备份与未知指纹拒绝、完整恢复，以及旧版本升级与恢复。
3. 在隔离 Electron 中验证动态文案、中英文切换、持久化、用户内容保护；区分真实产品页面与组件样本。
4. 构建并检查管理器的真实 JSON 链路和明暗主题页面，核对三个独立版本。
5. 同步长期模块规范、操作说明及本次分析和验证报告；不提交第三方资源。

## 验证结果

ASAR 共 738 个成员，仅 `package.json` 变化；内嵌 `main.js` 和样式另有变化，已独立审查。真实欢迎页发现并修复 8 条历史漏译，增加卡片范围识别及同文用户内容保护回归。

引擎 24 项、C# 集成 23 项通过；独立 Electron 组件、真实欢迎页中英文切换及偏好重启、管理器明暗主题页面检查通过。使用桌面现有代理启动器运行隔离副本，没有修改真实安装或系统代理。证据、产物指纹与未覆盖范围见 [2.23.1 摘要](../../analysis/reports/README.md#2231补丁-050-适配)。长期版本保留规则已同步模块规范与操作指南。
